## GATA x E-box spacing plot (done 2026-06-12)

Script: `scripts/plot_motif_spacing_focused.py`
Output: `2025_0517_official_EP300_K562_model/motif_spacing/GATA_Ebox_50bp/spacing_focused_v1.pdf`

- Data: `GATA_Ebox_50bp/raw_results.tsv` — 51 spacings (0–50 bp, 1 bp resolution), 4 orientations, 5 folds
- E-box (CACGTG) is palindromic → only 2 distinct cases: GATA+ (++ = +-) and GATA− (-+ = --)
- Plotted: `++` and `-+` mean lines with individual fold traces (thin, alpha=0.3)
- Horizontal dashed reference lines for GATA alone (0.176) and E-box alone (~0.000), derived as `mean(log2_fc_vs_baseline − log2_fc_vs_single_X)` from the paired dataset
- Vertical dashed line at spacing = 9 bp (peak)
- Colors from cmcrameri `managua` palette: positions 0.25 and 0.70
- Key result: sharp spike to log₂ FC ≈ 0.585 at spacing 9 in GATA− orientation only — recovers the known GATA–TAL1 E-box composite element grammar

## GATA n-copy spacing analysis — next task

### Data paths

| Model | n=2 | n=3 | n=4 |
|-------|-----|-----|-----|
| p300 BPNet | `2025_0517_official_EP300_K562_model/motif_spacing/GATA_n2_50bp/raw_results.tsv` | `GATA_n3_50bp/` | `GATA_n4_50bp/` |

| GATA2 BPNet | `K562_GATA2_BPNet/motif_spacing/GATA_50bp_n234/raw_results.tsv` | same | same |
| DNase ChromBPNet | `K562_DNase_ChromBPNet/motif_spacing/GATA_50bp_n2/raw_results.tsv` | `GATA_50bp_n3/` | `GATA_50bp_n4/` |

All files: columns `motif_counts`, `orientation_pattern`, `spacing` (0–50 bp), `model_fold`, `log2_fc_vs_baseline`, `log2_fc_vs_single`.

### Orientations (all unique — GATA is not palindromic)
- n=2: `++`, `+-`, `-+` (3 orientations; `--` excluded from experiment)
- n=3: `+++`, `++-`, `+-+`, `+--` (4 orientations)
- n=4: `++++`, `++--`, `+-+-`, `+--+` (4 orientations)

### Visualization options (discussed 2026-06-12, starting with n=2)

**Option A — 4-panel line plot (one per model):**
- 4 columns: p300, GATA1, GATA2, DNase; x = spacing; y = log2_fc_vs_baseline
- 3 colored lines per panel (++, +-, -+); horizontal dashed line = single GATA reference per model
- Best for: comparing spacing/orientation preference within each model

**Option B — model overlay per orientation:**
- 3 panels (one per orientation); 4 lines per panel (one per model, colored by model)
- Best for: asking whether the same spacing/orientation preference holds across models

**Option C — use log2_fc_vs_single as y-axis:**
- Same layouts but y = log2_fc_vs_single (marginal benefit of a 2nd GATA beyond the 1st)
- Normalizes out per-model single-GATA baseline; better for cross-model magnitude comparison

Recommended: start with Option A for n=2, use individual fold traces as in Ebox+GATA plot.
