## Key decisions

- **Accessibility is normalised PER CELL TYPE before pooling.** A pooled mean would leave
  library depth in the input and the model would read library rather than biology, the F-017
  mechanism. Live proof: MCF-7 normalises at log1p mean 2.63 against 4.55-4.76 for the
  others, its 4.6x shallower library.
- **Consequence: a multi-cell model must be scored with TARGET-derived statistics**, since
  it has no single training statistic. So `2.15` and `4.1` both take explicit
  `acc_mean`/`acc_std`, and the K562 evaluation includes a **policy-matched comparator** —
  the single-source model under the same normalisation — so the headline compares training
  sets and not normalisation policies.
- **MCF-7 kept unthinned** despite 4.6x shallower ATAC. F-017's own caveat: depth-matching
  is right for a transfer question and wrong for a production model. The leave-one-out
  design is the test if it turns out to matter.
- **Panel construction reproduces the existing cell types**, verified at r=1.0000 (EP300)
  and 0.9999 (ATAC), because K562 and GM12878 were not rebuilt and a divergence would have
  confounded the panel. Tn5 shift +4/-5 came from `0.22`'s calibration, not a guess.
- **Each cell type uses its own peaks, uncapped**, despite a 3.45x spread. Capping discards
  real sites and the leave-one-out design reports per-cell-type performance anyway.

## Lessons learned and gotchas

- **An ENCODE accession does not tell you what a file is.** Annotations of type
  `BPNet-model` publish observed and predicted profiles side by side, differing only in
  `output_type`, which is absent from the filename. The local convention of naming copies
  `<accession>_plus.bw` discards exactly that field. **Record `output_type` and `dataset`,
  and never take a signal track from `/annotations/` when `/experiments/` has one.**
- **An unpushed commit is not a backup.** Two losses in three days, both to resets, both
  found only because something downstream looked wrong.
- **Gate on integrity, not existence.** A wait keyed on `ls` fired while `create_predictions`
  was still streaming: 71 MB present, `gzip -t` failed. `4.6` now validates every arm.
- **A ratio measured on a benchmark's own input over the benchmark's own subset is not a
  property of the model.** F-021's 3.4x accessibility slope decomposes to x1.20 at the model,
  x1.85 after qnorm, x3.40 after the CRISPR subset.
- **ABC's rank qnorm discards a predicted track's scale entirely** (F-022), which retires
  every monotone-remapping fix without experiment and retrospectively explains F-013.
- `/tmp` is node-local; a script there is invisible to a compute node. Put it on Oak.
- `pkill -f <pattern>` matches your own ssh command line if the pattern appears in it.
