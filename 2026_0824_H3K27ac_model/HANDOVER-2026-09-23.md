## Key decisions

- **The oracle substitutes RANKS, not values.** ABC's qnorm keeps only within-class ranks
  (F-022), so pasting observed values would rank elements by the scale mismatch.
- **rE2G: every dataset shares the July ABC candidate regions** (the bigwigs were painted over
  them), and the ATAC-only and H3K27ac baselines were rerun on that set so every comparison is
  paired. The baselines reproduce the Feb 2025 runs (0.5449 against 0.5445).
- **The ranking loss is added to MSE, not a replacement for it.** It is scored over peak pairs
  **within a cell type**, using labels of the form `1 + cell index`, because negatives and scale
  still need MSE: ABC ranks all 153k regions. Cross-cell pairs would compare library depth.
  The validation loss includes the ranking term.
- **Partial ρ over all candidate regions is the leak-free screening metric.** Never select
  models on the tested elements.
- **The policy-matched comparator** (single-source model under target-derived normalisation)
  showed normalisation was worth +0.0014. Keep building such comparators.

## Lessons learned and gotchas

- Treat an upstream gain as unproven until the benchmark confirms it. That has now failed 6 times.
- `sacct -o SubmitLine` shows exactly what a workflow submitted.
- Monitors expire after 30 min, and when the socket dies they misreport "done".
- Heredocs nested inside single-quoted ssh broke twice. Write patch scripts locally and `scp`
  them.
- ABC's `create_neighborhoods` takes about 1 h per arm (three ATAC tagAligns). That is normal.
- rE2G `training_predictions.tsv`: `E2G.Score` = leave-one-chromosome-out CV;
  `E2G.Score_full` leaks.
- Ranking-model stopping epochs: rank2 mean 36.4, rank10 34.0, MSE baseline 34.6. No
  training-length confound (cf. F-019).
