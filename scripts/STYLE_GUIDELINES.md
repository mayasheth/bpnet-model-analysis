# Plot Style Guidelines

## Text
- Axis titles: sentence case (e.g., "Motif count" not "Motif Count")
- Use "p300" over "P300" in all text

## Axes
- No gridlines
- All black axes and axis ticks

## Color Palettes
- **Diverging**: 'managua'
- **Sequential**: 'PuBu'
- **4-color discrete** (e.g., orientations):
  - #e96a00 (orange)
  - #c5373d (red)
  - #0096a0 (teal)
  - #429130 (green)
- **2-color discrete** (p300 status):
  - p300+: #792374 (purple)
  - p300-: #49bcbc (cyan)

## Packages
- Avoid loading new packages unless automatically included with existing ones
