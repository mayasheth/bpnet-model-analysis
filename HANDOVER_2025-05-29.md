### 2. Multimodal BPNet implementation (sequence + accessibility)

**Architecture decision**: Single 5-channel concatenated input `(N, 5, 2114)`:
- Channels 0–3: one-hot DNA sequence
- Channel 4: accessibility signal (ATAC or DNase, log1p-normalized + standardized)

Middle fusion: separate initial Conv1d for seq (4→64) and acc (1→8), then concatenated before 8 dilated residual layers. DeepLIFT/SHAP on single input gives `attr[:, :4, :]` = sequence importance, `attr[:, 4:, :]` = accessibility importance.

## Key technical notes

- `tangermeme.ersatz.dinucleotide_shuffle(X, n=20)` returns shape `(batch, n, 4, L)`
- `bpnetlite.attribute.deep_lift_shap` accepts `references` as pre-built tensor `(N, n_shuffles, 5, L)` — used in SHAP script to handle mixed reference strategy
- Model trimming for n_layers=8: `47 + sum(2^i for i=1..8) = 557` each side → 2114 - 2×557 = 1000bp output ✓
- Reverse complement augmentation: sequence channels flip [0,1] (channels+positions), accessibility channel flips [1] (positions only)
